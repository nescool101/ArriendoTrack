# ArriendoTrack

Bilingual (ES/EN) landing page for ArriendoTrack — an automated rental billing service that sends billing statements (Cuentas de Cobro) via email to tenants and landlords.

## Features

- Bilingual support (Spanish / English) with language toggle
- Automated billing statement (Cuenta de Cobro) template preview
- Responsive design (mobile, tablet, desktop)
- Google Tag Manager integration (replace `GTM-XXXXXXX` with your container ID)
- WhatsApp floating contact button
- Pricing plans: Semestral ($10,000 COP / $3 USD) and Annual ($20,000 COP / $6 USD)
